# Simultaneous command - Test 2


I told the LLM Claude : " I want the robot to move forward 5 meters, then head as far to the left as possible, and then go to the top-right corner. "  

Claude then asked me for more details about my order, to which I replied. 
The journey finally began, but it took a long time because the robot was constantly adjusting its position. 
During navigation, Claude told me that it had already completed quite a few tasks and asked me if it should continue; that’s why the conversation with Claude is broken up into segments. 
Otherwise, everything was done directly based on my initial command. 
The robot eventually moved forward 5 meters; it then turned left and moved toward the wall, leaving enough space to avoid hitting the wall while turning. 
The robot then headed toward the upper-right corner. However, this corner was chosen based on its position when it had finished the previous step, not based on its starting position.
